# Brahms Trio: multi-bar rest example

This is a **source-page-3 excerpt**, bars 42–62 of the clarinet part, demonstrating the native Partsmith rest replacement. It is not a complete part.

- Bars 42–47: six whole-bar rests, replaced with a generated six-bar rest.
- Bars 48–52: original crop retained. The first three measures rest, but bar 51 has a sounding entrance and `p`; the whole strip must not be replaced.
- Bars 53–62: original crops retained. Some neighboring staff fragments remain beneath the final two strips.
- Bar labels are editorial source references placed above the strips, outside the music.

The PDF and editable `.partsmithproject` are generated by the production native layout/exporter. Open the project, select its first strip, and use **Multi-bar Rest → Restore Original Crop** to recover the six original measures. The embedded PDF is unchanged from the medium-skewed Brahms Trio test source. Other source pages remain embedded for context but are outside this excerpt's output scope.

The count is manually verified. Automatic note/rest recognition and partial-system compression are not implemented. See [the source audit](../../../Tests/extraction/rest-compression-review.md) for verified examples and negative controls.

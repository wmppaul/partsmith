# Current complete-score drafts

These are complete outputs from the native Partsmith planner and exporter, with initialized instrument lists and experimental local recognition of printed headings and repeat directions. The current Mac preview offers optional native heading, repeat-direction and paired-ending recognition through Auto. Original source engraving is retained; OCR text is not used to replace printed music or instructions.

The Mac preview includes the validated crop, detector, layout, persistence and planning-speed improvements. Links show both printed members of each recognized ending pair, and changing either source assignment invalidates linked automatic copies.

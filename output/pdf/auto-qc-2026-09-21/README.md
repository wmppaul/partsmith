# Current complete-score drafts

These are complete outputs from the native Partsmith planner and exporter, with initialized instrument lists and experimental local recognition of printed headings and repeat directions. The experimental recognition is not enabled in the Mac app. Original source engraving is retained; OCR text is not used to replace printed music or instructions.

- **Brahms Quartet Op. 67, IMSLP93521, latest draft:** [Violin I](brahms-quartet-93521-connector8/Violin%20I.pdf), [Violin II](brahms-quartet-93521-connector8/Violin%20II.pdf), [Viola](brahms-quartet-93521-connector8/Viola.pdf), [Violoncello](brahms-quartet-93521-connector8/Violoncello.pdf). All 151 systems appear in each part, across 17, 16, 16 and 15 output pages. The folder includes an editable `.partsmithproject`, source-bound manifest, plan, and full corrected review source. The older `brahms-quartet-93521` folder remains available for comparison.
- **Mozart, Ave Verum Corpus:** all eight printed parts, eight systems each, one page per part, under [ave-verum](ave-verum/). An editable project and manifest are included.

**Both sets remain drafts.** The latest Quartet reduces whole neighboring-staff inclusions from 20 to 11 across its 604 crops; partial fragments remain. Seven large headings and the page-28 Da Capo sentence are retained. The page-26 destination cross is now also retained in all four parts, using matched original source pixels. Rehearsal letters, endings and other shared directions remain incomplete. Ave retains all 64 independently reviewed own-notation envelopes, including every figured-bass row; its heading copies expose duplicate Adagio markings in Basso and Violin I, and shared source bar numbers remain incomplete. These limitations matter when playing from the parts.

The Mac preview includes the validated crop, detector, layout, persistence and planning-speed improvements. Its Auto button does not claim the experimental direction-recognition coverage shown here. Use [the current Mac build](../../../artifacts/macos/Partsmith-extraction-preview-macos.zip) for editing these projects.

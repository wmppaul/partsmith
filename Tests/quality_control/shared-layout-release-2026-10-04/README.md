# Shared scale, gap and margins

Scale, System Gap and Side Margins now use score-wide settings by default. Editing them from any linked part updates every linked part and supplies the defaults for parts added later. The Inspector identifies the scope as Score Layout or Part Override. Customize This Part freezes the current values for one part; turning it off rejoins the current score settings. Use These Settings for All Parts promotes the selected part's effective values and clears all three layout overrides in one undoable operation. Other part settings and all saved source crops remain unchanged.

Layout, PDF export and Preview resolve the same settings, including asymmetric side margins. Deferred slider commits are guarded by their original scope so callbacks from a disappearing local control cannot overwrite shared settings. Old files currently retain their appearance when opened: matching layouts are linked and differing layouts are preserved locally. Backward compatibility is not a future product requirement, per the user's clarification.

# Repeated-heading matching remains rejected for production

The initial Python experiment removed three duplicate copies across complete Ave, KV498, and corrected Brahms outputs. Independent review found that Ave Basso’s only remaining Adagio would sit below its own staff as neighboring Violin I notation. That cannot replace a tempo copy above the Basso staff.

Additionally, the initial full-width same-system matching could mistake the same word later at another bar for the starting tempo. It does not sufficiently inspect adjacent letters outside the matched rectangle. High foreground correlation is not enough to establish musical ownership or placement.

The native candidate excludes all equivalent-glyph metadata and matching. It only suppresses a copy when its exact source ink is already inside the same source rectangle of the part. Native Ave therefore remains unchanged with its known duplicate Adagio problem.

Any later matching experiment must require equivalent musical x alignment, location above the recipient’s first staff, complete glyph containment and context/adjacent-letter controls. No cleanup or whiteouts were introduced. The independent Ave source guard is frozen separately and must not be moved.

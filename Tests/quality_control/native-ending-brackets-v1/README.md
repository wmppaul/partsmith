# Native paired ending brackets — scratch candidate

The native detector found all five independently known first/second ending pairs across the complete 68 pages of Mozart KV498 and Brahms IMSLP93521. The native path produces 576 geometry proposals, 412 merged lines, and 13 numeral-like candidates. Pair ownership/geometry rejects three actual musical-fragment false numerals; ten known brackets remain in five pairs, with no extra selected pair. This is a bounded two-score result, not a broad recall guarantee.

The algorithm uses the verified physical first staff of each system, a thin horizontal line with a descending hook, local accurate/fast Vision OCR, a closed right hook for the first ending, and unique adjacent pairing. Literal fast OCR “I” remains recorded as ambiguous evidence; it is never transcribed as a replacement numeral. Printed source pixels supply every numeral and line in the output. No score/page IDs or oracle rectangles enter recognition.

Sixty-six controls pass, including actual beam false numerals and image-based Roman-I/prose negatives. Independent code review identified missing-input-page adjacency and final cancellation gaps; both were fixed and covered before the final full 68-page rerun. Unknown/unresolved pages block pairing, and a second ending cannot validate multiple first endings. OCR errors do not silently become successful empty recognition.

All 27 earlier heading/navigation/destination copies are retained. Fifteen new source rows add all eight ending brackets to each lower part, 24 bracket copies in total.

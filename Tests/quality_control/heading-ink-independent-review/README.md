# Independent heading ink containment review

**Approved for the narrow same-source duplicate suppression. No remaining code blocker.** This review does not certify complete extracted parts. The separate root change making reviewed recipient marking lists authoritative also has no blocker.

The native candidate measures original rendered source pixels inside the existing padded heading copy. It suppresses that copy only when the measured ink, including a one-pixel guard, lies inside both the heading rectangle and the recipient's main crop. It does not match equivalent words elsewhere on the page. A failed or empty measurement retains the copy. Legacy metadata without ink bounds retains previous behavior.

Independent synthetic tests cover top-down coordinates, white compositing of alpha pixels, faint gray254 ink outside the black letters, empty regions, six malformed rectangles, disjoint metadata, owner-versus-lower-recipient behavior, legacy decoding, and unchanged main crop geometry. All 14 pass. Review initially found and resolved disjoint metadata acceptance, ignored254 pixels, and missing measurement-loop cancellation checks. The enlarged real Brahms serif-negative source was also inspected: original A caps, i dots and parentheses extend outside the OCR word box, which cannot safely serve as suppression evidence.

The complete native exports contain 15 parts, 111 pages and 1,073 main crops. Every page was independently rendered at 144 dpi and compared with its baseline; 110 are pixel-identical. All candidate pages were also checked in contact sheets. The sole changed page, KV498 Clarinet 6, was inspected at full-page resolution: Rondo. Allegretto. remains complete once above its intended staff; the duplicate heading row disappears and the music moves up. Main source crops, staff identities, system order and page counts are unchanged throughout all three scores. All 39 corrected Brahms source pages also render identically, despite different PDF byte hashes.

## Review boundaries

The helper only groups accepted rectangles. It does not prove that every OCR word is a global direction. Original classification and source-ownership gates remain necessary. A rectangular union can enclose extra ink in empty corners; the detector must measure the full original-source union before using ink containment to suppress a duplicate. The independent faint-corner control exercises that distinction.

Horizontally overlapping headings with a real vertical gap remain separate and still face the existing single copied-row limitation. This is intentionally outside the bounded overlapping-fragment repair; the corpus review must not claim all multi-line layouts are now handled.

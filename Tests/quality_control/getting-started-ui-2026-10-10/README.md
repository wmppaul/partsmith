# Illustrated Getting Started: native UI verification

The tutorial was exercised in the exact universal Alpha 6 release app. A new disposable project imported all 25 pages of the Brahms IMSLP09200 source; deskew saved eight corrections. Native name picking read 1. Violine, 2. Violine, Bratsche and Violoncell. Done returned to the same setup. Auto and Add Parts created four parts with 120 source systems each, without an acknowledgement checkbox. The enlarged assignment screen selected four staves by drag. Preview exposed blue crop handles and Expand Crop; the Inspector displayed shared Scale, Side Margins and System Gap.

File Save wrote a separate editable project, and Source Export All generated every part PDF: 14, 13, 13 and 14 pages respectively (54 total). Source hash, saved JSON hash, actual PDF hashes and screenshot hashes are in [receipt.json](receipt.json). These UI-generated PDFs use a printed header and deskew corrections; the separate Core recheck uses the unrectified source and a typed title and has different pagination. Neither inherits the other generation's musical review.

The additional manual-name screenshot shows an empty box beside an unlabeled continuation staff opening the typed field, staff count and enabled Add Instrument button. That demonstration remained pending and was canceled; no fifth instrument was added to the saved project.

All screenshots were captured through native computer use. The [raw captures and callout source](../../../docs/images/getting-started/README.md) permit reproduction of the annotations. The renderer preserves the app pixels apart from cropping/resizing, and adds vector callouts. Root visually inspected all ten figures. An independent agent verified all ten rendered images and both guides' button labels, workflow, links and anchors. The independently reviewed manual-name PNG hash is `77e509eed6501c6baff9edc2a47626017d4975bcd6cdcef521204cb52ed1655d`.

This is workflow/UI verification, not a performance-readiness certificate for the extracted score. The [Brahms recheck](../../../docs/brahms-quartet-review.md) records notation and shared-direction findings. No production app source was changed for the guide.

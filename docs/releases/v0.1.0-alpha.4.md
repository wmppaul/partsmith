Assign systems more easily when instruments appear and disappear within a score.

## What's new

- Drag across the printed staves to select a system, with live selection highlights. Click to adjust, or Shift-drag to add staves.
- **Bars in system** can suggest a count from printed barlines. The count remains editable; your entries and saved assignments take precedence over automatic suggestions.
- Assignment controls and saved-system lists show **Page N · System N** so page-local numbering is clear.
- Revisit a saved system or page to restore its bar count, first bar, selected staves, and instruments. Returning after assigning the last system opens the saved assignment rather than the next empty slot.
- Updated instructions and limitations for this assignment workflow.

Automatic counts need corroborating barlines across multiple selected staves. Single-staff systems, disconnected barlines, and ambiguous scans still need a manual count. Check pickups and split measures before assigning rests for omitted instruments.

This release includes the Auto workflow, shared layout controls, Preview crop editing, and other improvements from alpha.3.

## Download and open

Download **Partsmith-v0.1.0-alpha.4-macos.zip** below, unzip it, and open `Partsmith.app`. Requires **macOS 14 or later** and supports **Apple Silicon and Intel**. The app is ad hoc signed, not notarized; if macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to launch it.

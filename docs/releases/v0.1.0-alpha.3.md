Start with the **Auto Extract** magic wand to turn a full-score PDF into editable instrument parts, entirely offline on your Mac.

## What's new

- Guided Auto setup with selected-page thumbnails, optional **Deskew & Align Pages**, printed instrument-name picking, and automatic source headers. **Done — Back to Auto Extract** returns you from the score to setup.
- Improved staff detection and crop preservation for scans, with enlarged instrument assignment and reusable layouts for scores whose instrumentation changes between systems.
- Reversible counting and compression of eligible full-bar rest strips; counted rests can also represent confirmed silent instruments omitted from the score.
- Crop editing directly in **Preview**: drag a system's top or bottom handle, with the same crop used in Source and PDF export.
- Shared **Scale**, **System Gap**, and **Side Margins**, with **Customize This Part** overrides. Gaps stay at the requested 4–200 pt, new projects use 18 pt side margins, and requested enlargement is applied with an overflow warning instead of a silent width cap.
- Background preview updates, steadier horizontal source alignment, and optional detection/copying of some shared directions and endings.
- Rewritten Getting Started, workflow documentation, and known limitations for the current Auto flow.

## Download and open

Download **Partsmith-v0.1.0-alpha.3-macos.zip** below, unzip it, and open `Partsmith.app`. Requires **macOS 14 or later** and supports **Apple Silicon and Intel**. The app is ad hoc signed, not notarized; if macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to launch it.

[Getting started](https://github.com/wmppaul/partsmith/blob/v0.1.0-alpha.3/README.md#getting-started-with-auto-extract) · [Known limitations](https://github.com/wmppaul/partsmith/blob/v0.1.0-alpha.3/KNOWN_LIMITATIONS.md)

This is an assisted-extraction alpha. Review intended notes, lyrics, shared markings, rest counts and page turns before performance. Changing instrumentation and difficult overlapping notation can still need manual correction. This is not note transcription or general notation reflow.

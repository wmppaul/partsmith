Better rest compression for the Mozart piano concerto example, with consecutive silent systems grouped by default.

## What's new

- Recognizes opening clarinet and horn rests when a common-time C is separated from the treble clef by an empty key-signature column.
- Recognizes piano grand-staff rests when both hands have matching whole-rest counts and barlines. Both staves, clefs and the brace remain, with one shared count.
- Consecutive inserted rests join by default, even without optional first-bar numbers. A compressed opening can extend through following inserted rests when its ending is a plain barline. Individual source entries stay editable, and **Join with previous rest** can be turned off.
- Preserves copied opening instructions such as Allegro / TUTTI when they extend past the clef and meter, before the first rest.
- Keeps boundaries at playing passages, later printed context or directions, explicit breaks, missing source intervals, contradictory bar numbers, and uncertain/double/repeat endings.

For an existing project, choose **Find & Compress Rests** to check its remaining original strips. Saved inserted rests use the new default grouping; explicit separation choices are preserved. **Restore Original Crop** and Undo remain available.

Mixed playing/resting systems are still kept whole. Uncertain neighboring ink can prevent compression, and later printed prefixes remain separate to preserve possible clef, key, meter or direction changes.
